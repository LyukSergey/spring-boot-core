# ПЗ-1. Умова завдання та критерії оцінювання

> **Тип:** практичне заняття (3 пари, 6 годин).
> **Максимальний бал:** **20**.
> **Повна інструкція з реалізації:** див. [`pz-12.md`](./pz-12.md).
> Цей файл — лише **умова** й **бали**. Як саме робити — у `pz-12.md`.

---

## Умова

Розробити Spring Boot (Maven) застосунок «**Облік відсутності студентів**», який:

1. За розкладом (**cron job**) читає **Google Sheet** з обліку відвідуваності.
2. Таблиця містить **людей (ПІП)**, згрупованих у **групи студентів**; колонки — **дати**.
3. На перетині **ПІП × дата** стоїть **позначка відсутності**: `хворий`, `санчастина`, `відрядження`, `відпустка`.
4. Бекенд **рахує** кількість по кожній категорії (скільки хворих, скільки у відрядженні тощо).
5. Формує **списки по категоріях і по групах** (напр. «Хворі:» → перелік `Прізвище Ім'я`).
6. **Надсилає email** зі зведеним звітом.

## Куди підключатись / що використати

- **Google Sheets API v4** — читання таблиці.
- **Автентифікація:** Service Account (JSON-ключ), таблиця **пошарена** на email сервіс-акаунта (право Viewer).
- **Ключ** — файл `google-credentials.json` у `src/main/resources`, **обов'язково в `.gitignore`**.
- **SMTP** (Gmail App Password або корпоративний) — для розсилки.
- **Планувальник:** `@Scheduled(cron = ...)`, розклад із `application.yml`.

## Формат вхідної таблиці

| Група | ПІП | 2026-09-01 | 2026-09-02 | ... |
|-------|-----|-----------|-----------|-----|
| КН-11 | Іваненко Іван |  | х |  |

Позначки: `х`/`хворий`, `сч`/`санчастина`, `вд`/`відрядження`, `вп`/`відпустка`; порожньо = присутній.

## Критерії оцінювання (як виставляється бал)

| Рівень виконання | % від 20 | Бал | Що це означає |
|------------------|----------|-----|----------------|
| **Повністю + тести** | 100% | **20** | Усі 6 пунктів працюють на живих даних; email приходить із коректними цифрами й списками; є тести (підрахунок + розпізнавання клітинки); секрети не в git |
| **Повністю без тестів** | 85% | **17** | Усе працює end-to-end, але тестів немає або вони формальні |
| **Частково (email є, але)** | 70% | **14** | Читання+підрахунок+email працюють, але є суттєвий недолік: не по групах / не всі категорії / хардкод замість конфігу |
| **Половина** | 50% | **10** | Читає таблицю й рахує, але **email не відправляється** або cron не налаштований (запуск лише вручну) |
| **Базове** | 30% | **6** | Проєкт піднімається, підключення до Sheets є, дані читаються, але далі підрахунку/звіту не дійшло |
| **Не працює / не здано** | 0% | **0** | Не компілюється, не підключається до Sheets, або відсутнє |

### Штрафи (віднімаються від набраного)

- **−3** — `google-credentials.json` або пароль SMTP закомічені в git (витік секрету).
- **−2** — весь код в одному класі (немає поділу на модель/читач/сервіс звіту/email).
- **−2** — падає при порожній таблиці / порожньому рядку (немає захисту).

### Бонус (не більше загального максимуму 20)

- **+2** — HTML-лист (`MimeMessageHelper`) замість plain text.
- **+1** — фільтр за поточним тижнем/днем або кілька отримувачів (куратори груп).

## Definition of Done (чек-лист здачі)

- [ ] Google Cloud проєкт + Sheets API увімкнено; сервіс-акаунт створено; таблиця пошарена.
- [ ] `application.yml` заповнено (spreadsheet-id, range, SMTP, cron, email).
- [ ] Запуск (крон або `CommandLineRunner`) → на пошту приходить звіт із коректними цифрами та списками по групах.
- [ ] Код поділено на шари (модель / читач Sheets / сервіс звіту / email / cron-джоба).
- [ ] `mvn test` — зелений.
- [ ] Секрети (`google-credentials.json`, паролі) **не** в git.
