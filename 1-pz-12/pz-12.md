# ПЗ-12. Spring Boot + Google Sheets: облік відсутності студентів і email-звіт

## Мета

Створити Spring Boot (Maven) застосунок, який:

1. За розкладом (**cron job**) читає **Google Sheet** з обліку відвідуваності.
2. Таблиця містить **людей (ПІП)** згрупованих у **групи студентів**, а колонки — це **дати**.
3. На перетині **ПІП × дата** стоїть **відмітка про відсутність**: `хворий`, `санчастина`, `відрядження`, `відпустка`.
4. Бекенд рахує кількість по кожній категорії (скільки хворих, скільки у відрядженні тощо).
5. Формує **списки по категоріях і по групах**: напр. «Хворі:» → перелік `Ім'я Прізвище`, «Відрядження:» → перелік і т.д.
6. Надсилає **email** зі зведеним звітом.

---

## Структура Google Sheet (вхідні дані)

Домовляємось про формат таблиці, щоб парсер був простим і стабільним.

| Група | ПІП | 2026-09-01 | 2026-09-02 | 2026-09-03 | ... |
|-------|-----|-----------|-----------|-----------|-----|
| КН-11 | Іваненко Іван |  | х | вд |  |
| КН-11 | Петренко Петро | сч |  |  |  |
| КН-12 | Сидоренко Сидір | вп | вп | вп |  |

**Умовні позначки в клітинках** (нормалізуємо на бекенді):

| У клітинці | Категорія (enum) |
|-----------|------------------|
| `х`, `хворий` | SICK (хворий) |
| `сч`, `санчастина` | MEDICAL_UNIT (санчастина) |
| `вд`, `відрядження` | BUSINESS_TRIP (відрядження) |
| `вп`, `відпустка` | VACATION (відпустка) |
| порожньо / інше | присутній (не рахуємо) |

> **Порада:** тримайте перші 2 колонки фіксованими (`Група`, `ПІП`), а решту — датами у форматі `YYYY-MM-DD`. Так код однозначно відрізняє «шапку людини» від «колонок-дат».

## Крок 1. Створити Google Cloud проєкт і Service Account

1. Відкрий https://console.cloud.google.com/ → **Create Project** (напр. `attendance-bot`).
2. **APIs & Services → Library** → увімкни **Google Sheets API**.
3. **APIs & Services → Credentials → Create Credentials → Service Account**:
   - Назва: `sheets-reader`.
   - Роль можна не давати (доступ до конкретного файлу даємо через шеринг).
4. Відкрий створений Service Account → вкладка **Keys → Add Key → Create new key → JSON**.
   - Завантажиться файл ключа, напр. `sheets-reader-xxxx.json`.
5. **Поділись Google-таблицею** з email сервіс-акаунта (виглядає як `sheets-reader@attendance-bot.iam.gserviceaccount.com`) — права **Viewer** достатньо.
6. Поклади ключ у проєкт: `src/main/resources/google-credentials.json`
   - ⚠️ **Додай його в `.gitignore`** — це секрет, не комітити!

### 4.1. Enum категорій відсутності

`src/main/java/com/example/attendance/model/AbsenceType.java`:

```java
package com.example.attendance.model;

import java.util.Arrays;

/** Категорії відсутності. Кожна знає свої «синоніми» з клітинок таблиці. */
public enum AbsenceType {
    SICK("Хворі", "х", "хворий", "хвора"),
    MEDICAL_UNIT("Санчастина", "сч", "санчастина"),
    BUSINESS_TRIP("Відрядження", "вд", "відрядження"),
    VACATION("Відпустка", "вп", "відпустка");

    private final String title;      // як показати в звіті
    private final String[] aliases;  // варіанти написання в клітинці

    AbsenceType(String title, String... aliases) {
        this.title = title;
        this.aliases = aliases;
    }

    public String title() { return title; }

    /** Розпізнати клітинку → категорія, або null якщо присутній/невідомо. */
    public static AbsenceType fromCell(String raw) {
        if (raw == null || raw.isBlank()) return null;
        String v = raw.trim().toLowerCase();
        return Arrays.stream(values())
                .filter(t -> Arrays.asList(t.aliases).contains(v))
                .findFirst()
                .orElse(null);
    }
}
```

## Крок 5. Читання Google Sheet

### 5.1. Бін клієнта Sheets

`src/main/java/com/example/attendance/sheets/GoogleSheetsConfig.java`:

```java
package com.example.attendance.sheets;

import com.google.api.client.googleapis.javanet.GoogleNetHttpTransport;
import com.google.api.client.json.gson.GsonFactory;
import com.google.api.services.sheets.v4.Sheets;
import com.google.api.services.sheets.v4.SheetsScopes;
import com.google.auth.http.HttpCredentialsAdapter;
import com.google.auth.oauth2.GoogleCredentials;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.core.io.Resource;

import java.io.InputStream;
import java.util.List;

@Configuration
public class GoogleSheetsConfig {

    @Value("${google.sheets.credentials-path}")
    private Resource credentials;

    @Bean
    public Sheets sheetsClient() throws Exception {
        try (InputStream in = credentials.getInputStream()) {
            GoogleCredentials creds = GoogleCredentials
                    .fromStream(in)
                    .createScoped(List.of(SheetsScopes.SPREADSHEETS_READONLY));

            return new Sheets.Builder(
                    GoogleNetHttpTransport.newTrustedTransport(),
                    GsonFactory.getDefaultInstance(),
                    new HttpCredentialsAdapter(creds))
                    .setApplicationName("attendance-report")
                    .build();
        }
    }
}
```

### 5.2. Читач + парсер таблиці

`src/main/java/com/example/attendance/sheets/AttendanceReader.java`:

```java
package com.example.attendance.sheets;

import com.example.attendance.model.AbsenceRecord;
import com.example.attendance.model.AbsenceType;
import com.google.api.services.sheets.v4.Sheets;
import com.google.api.services.sheets.v4.model.ValueRange;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import java.time.LocalDate;
import java.util.ArrayList;
import java.util.List;

/**
 * Читає таблицю формату:
 *   [0]=Група, [1]=ПІП, [2..]=дати (YYYY-MM-DD у шапці).
 * На перетині ПІП×дата — позначка відсутності. Перетворює це на плаский
 * список {@link AbsenceRecord}.
 */
@Component
public class AttendanceReader {

    private final Sheets sheets;
    private final String spreadsheetId;
    private final String range;

    public AttendanceReader(Sheets sheets,
                            @Value("${google.sheets.spreadsheet-id}") String spreadsheetId,
                            @Value("${google.sheets.range}") String range) {
        this.sheets = sheets;
        this.spreadsheetId = spreadsheetId;
        this.range = range;
    }

    public List<AbsenceRecord> read() throws Exception {
        ValueRange resp = sheets.spreadsheets().values()
                .get(spreadsheetId, range)
                .execute();

        List<List<Object>> rows = resp.getValues();
        List<AbsenceRecord> result = new ArrayList<>();
        if (rows == null || rows.size() < 2) return result;

        // Рядок 0 — шапка: колонки-дати починаються з індексу 2.
        List<Object> header = rows.get(0);
        List<LocalDate> dates = new ArrayList<>();
        for (int c = 2; c < header.size(); c++) {
            dates.add(parseDate(cell(header, c)));
        }

        // Дані з рядка 1.
        for (int r = 1; r < rows.size(); r++) {
            List<Object> row = rows.get(r);
            String group = cell(row, 0);
            String name = cell(row, 1);
            if (group.isBlank() || name.isBlank()) continue;

            for (int c = 2; c < row.size(); c++) {
                AbsenceType type = AbsenceType.fromCell(cell(row, c));
                if (type == null) continue;              // присутній / невідомо
                LocalDate date = (c - 2) < dates.size() ? dates.get(c - 2) : null;
                result.add(new AbsenceRecord(group, name, date, type));
            }
        }
        return result;
    }

    private static String cell(List<Object> row, int i) {
        return (row != null && i < row.size() && row.get(i) != null)
                ? row.get(i).toString().trim() : "";
    }

    private static LocalDate parseDate(String s) {
        try { return LocalDate.parse(s); } catch (Exception e) { return null; }
    }
}
```

## Крок 6. Підрахунок і формування звіту

`src/main/java/com/example/attendance/report/AttendanceReportService.java`:

```java
package com.example.attendance.report;

import com.example.attendance.model.AbsenceRecord;
import com.example.attendance.model.AbsenceType;
import org.springframework.stereotype.Service;

import java.util.*;
import java.util.stream.Collectors;

/** Рахує підсумки й будує текст звіту зі списками по категоріях та групах. */
@Service
public class AttendanceReportService {

    public String buildReport(List<AbsenceRecord> records) {
        StringBuilder sb = new StringBuilder();

        // Беремо унікальних людей на категорію (щоб студент, відсутній 3 дні,
        // не рахувався тричі). Якщо треба рахувати «людино-дні» — прибери distinct.
        sb.append("ЗВЕДЕНИЙ ЗВІТ ПРО ВІДСУТНІСТЬ\n");
        sb.append("=============================\n\n");

        // 1) Підсумкові цифри по категоріях.
        sb.append("ПІДСУМОК:\n");
        for (AbsenceType type : AbsenceType.values()) {
            long count = records.stream()
                    .filter(r -> r.type() == type)
                    .map(r -> r.group() + "|" + r.fullName())
                    .distinct()
                    .count();
            sb.append(String.format("  %-14s : %d%n", type.title(), count));
        }
        sb.append("\n");

        // 2) Детальні списки: по кожній категорії — розбивка по групах.
        for (AbsenceType type : AbsenceType.values()) {
            List<AbsenceRecord> byType = records.stream()
                    .filter(r -> r.type() == type)
                    .collect(Collectors.toList());
            if (byType.isEmpty()) continue;

            sb.append(type.title().toUpperCase()).append(":\n");

            Map<String, List<String>> byGroup = byType.stream()
                    .collect(Collectors.groupingBy(
                            AbsenceRecord::group,
                            TreeMap::new,
                            Collectors.mapping(AbsenceRecord::fullName,
                                    Collectors.toCollection(TreeSet::new))
                            .andThen(set -> new ArrayList<>(set))));

            byGroup.forEach((group, names) -> {
                sb.append("  Група ").append(group).append(":\n");
                names.forEach(n -> sb.append("    - ").append(n).append("\n"));
            });
            sb.append("\n");
        }
        return sb.toString();
    }
}
```

> **Що рахуємо:** тут — унікальних студентів на категорію (`distinct` по «група|ПІП»). Якщо потрібні **людино-дні** (кожен день відсутності окремо) — прибери `.distinct()` у підсумку.

## Крок 7. Відправка email

`src/main/java/com/example/attendance/report/EmailSender.java`:

```java
package com.example.attendance.report;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.mail.SimpleMailMessage;
import org.springframework.mail.javamail.JavaMailSender;
import org.springframework.stereotype.Component;

import java.time.LocalDate;

@Component
public class EmailSender {

    private final JavaMailSender mailSender;
    private final String to;
    private final String subjectPrefix;
    private final String from;

    public EmailSender(JavaMailSender mailSender,
                       @Value("${report.email.to}") String to,
                       @Value("${report.email.subject-prefix}") String subjectPrefix,
                       @Value("${spring.mail.username}") String from) {
        this.mailSender = mailSender;
        this.to = to;
        this.subjectPrefix = subjectPrefix;
        this.from = from;
    }

    public void send(String body) {
        SimpleMailMessage msg = new SimpleMailMessage();
        msg.setFrom(from);
        msg.setTo(to);
        msg.setSubject(subjectPrefix + " — " + LocalDate.now());
        msg.setText(body);
        mailSender.send(msg);
    }
}
```

## Крок 8. Cron-джоба, що все зв'язує

`src/main/java/com/example/attendance/AttendanceJob.java`:

```java
package com.example.attendance;

import com.example.attendance.model.AbsenceRecord;
import com.example.attendance.report.AttendanceReportService;
import com.example.attendance.report.EmailSender;
import com.example.attendance.sheets.AttendanceReader;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

import java.util.List;

@Component
public class AttendanceJob {

    private static final Logger log = LoggerFactory.getLogger(AttendanceJob.class);

    private final AttendanceReader reader;
    private final AttendanceReportService reportService;
    private final EmailSender emailSender;

    public AttendanceJob(AttendanceReader reader,
                         AttendanceReportService reportService,
                         EmailSender emailSender) {
        this.reader = reader;
        this.reportService = reportService;
        this.emailSender = emailSender;
    }

    /** Розклад береться з application.yml → report.cron. */
    @Scheduled(cron = "${report.cron}")
    public void run() {
        try {
            log.info("Attendance job started");
            List<AbsenceRecord> records = reader.read();
            String report = reportService.buildReport(records);
            emailSender.send(report);
            log.info("Attendance report sent ({} records)", records.size());
        } catch (Exception e) {
            log.error("Attendance job failed", e);
        }
    }
}
```

## Можливі покращення (на «відмінно»)

- **HTML-лист** замість plain text (`MimeMessageHelper`, `setText(html, true)`) — таблиці, кольори по категоріях.
- **Фільтр за поточним тижнем/днем** — рахувати лише сьогоднішні дати.
- **Кілька отримувачів** / різні листи по кураторах груп.
- **Ретраї** при збої мережі Google API.
- **Кешування** ключа й з'єднання, обробка порожньої таблиці.
- **Профілі** (`application-dev.yml` / `application-prod.yml`) з різними cron і адресатами.
